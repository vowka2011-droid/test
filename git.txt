git init - создает локальный репозиторий
git add . - для добаления файла репозиторий (. = все файлы)
git commit -m "<комментарий>" - взять и зафиксирвать все изменения(новая версия проекта)
git branch -M main - решается в какой ветке ты работаешь(в основной или тестовой)
git remote add origin https://github.com/vowka2011-droid/test.git - связывает твой репазиторий в git с github по ссылке
git push -u origin main - отправляет изменения в основную ветку github
git pull - получение изменений из github
